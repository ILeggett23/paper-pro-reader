# Paper Pro Reader A/B qualification

Use the same book, passage, brightness, and orientation for A and B. After each
test record taps, elapsed time, readability, interruption, ghosting, perceived
latency, and how easily reading resumed. Native writing is not identical to
KOReader ink; describe differences instead of forcing a false equivalence.

## 1 — Dictionary

**A:** Use KOReader's existing dictionary interaction on a selected word.

**B:** Select the same word and use Paper Pro Reader's Define overlay.

Record:

- actions/taps to definition and dismissal;
- popup location and whether it obscures the word;
- readability and ghosting;
- whether the page/location changed.

## 2 — Notes

**A:** Create/edit a note through the existing KOReader note flow.

**B:** Create/edit the same-length note through the contextual NoteOverlay.

Record creation time, number of actions, book visibility, keyboard ergonomics,
editing clarity, marker visibility, and return-to-reading friction.

## 3 — Handwriting

**A:** Use stock/native writing in a comparable blank or margin area.

**B:** Use Paper Pro Reader Ink Mode for three lines, an edge stroke, eraser,
Undo, and Redo.

Record pen-down latency, continuity, missing points, edge behavior, eraser,
visual quality, ghosting, and touch behavior while Marker is active. Native and
KOReader storage/anchoring differ; compare feel, not feature parity.

## 4 — AI question

**A:** Read a passage, ask the same question through an external ChatGPT
interface, then return to the book.

**B:** Select the passage and use typed Quick Ask.

Question: `What does the author mean by this?`

Record total elapsed time, context-copying effort, interruption, answer
relevance, position preservation, and ease of resuming.

## 5 — Book Writes Back

Paper Pro Reader product-flow test:

1. Select a passage.
2. Write `Why does this matter?`.
3. Submit and time until the completed answer.
4. Record recognized question accuracy.
5. Toggle Text/Handwriting response style.
6. Ask `Can you give me an example?` as a follow-up.
7. Expand, enter Full Study, return to reading, and dismiss.

Record friction, Marker canvas comfort, response readability, refresh count,
ghosting, context association, and reading-position restoration.

## 6 — Offline/restart

1. Disable Paper Pro Wi-Fi.
2. Submit one typed and one written question.
3. Confirm both show Queued and reading remains usable.
4. Exit and relaunch KOReader.
5. Confirm both still appear in AI History.
6. Re-enable Wi-Fi and confirm each completes once.

Record duplicates, lost questions, ordering, unexpected dialogs, and time from
reconnect to saved answer.
